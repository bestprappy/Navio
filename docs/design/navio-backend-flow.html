One way in

Every application request enters through NGINX and is routed by the API Gateway. Services are never reachable from the internet.

One schema per service

Each service owns its schema and no service reads another's tables. Cross-domain data moves through APIs and events only.

Events, not calls

A service commits its data and an outbox row together, then publishes to Kafka. Consumers stay eventually consistent and idempotent.

Failure stays local

If AI, Kafka, a provider, or observability is down, the core planning and community flows keep working.
