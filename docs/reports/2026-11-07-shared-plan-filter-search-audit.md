## Recommended next search work — not implemented in this UI revision

1. Define evidence-based seasonal search semantics separately from weather guarantees, then replace the blanket season block with tested, visible interpretation. Do not silently map seasons to the same months worldwide.
2. Add curated, explicit geographic region membership (Europe) and request clarification for subjective groupings (Western countries).
3. Add conservative typo correction for known locations and travel vocabulary, including transpositions such as musuem. Preserve user intent and label corrections.
4. Broaden conversational filler recognition carefully, with held-out false-positive tests. Never drop unknown specific requirements just to show more plans.
5. Make rewritten country aliases display canonical names rather than “u k”/“u s.”

The algorithm is deterministic and conservative, not a general natural-language search engine. Empty catalogue cases return no invented plan titles; unsupported/ambiguous requests can still have no useful rewrite. The audit does not claim every example is handled successfully.
